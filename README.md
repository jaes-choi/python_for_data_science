## Notebook에서 자주 사용하는 단축키

### 셀 실행
- `Ctrl+Enter` — 현재 셀 실행
- `Shift+Enter` — 셀 실행 후 다음 셀로 이동
- `Alt+Enter` — 셀 실행 후 아래에 새 셀 추가

### 명령 모드 / 편집 모드 전환
- `Esc` — 명령 모드 (셀 선택 및 조작)
- `Enter` — 편집 모드 (셀 안에 코드 입력)

### 셀 추가
- `A` — 위에 셀 추가
- `B` — 아래에 셀 추가

### 셀 복사·붙여넣기·삭제·취소
- `C` / `V` / `X` — 셀 복사 / 붙여넣기 / 잘라내기
- `D D` — 셀 삭제 (`D`를 연속 두 번 입력)
- `Z` — 셀 삭제 등 작업 취소

### 셀 나누기·합치기
- `Ctrl+Shift+-` — 커서 위치에서 셀 분리
- `Shift+M` — 선택한 셀 합치기

### 코드 / Markdown 전환
- `Y` — Code 셀로 변경
- `M` — Markdown 셀로 변경

### 저장
- `Ctrl+S` — Notebook 저장

### 커널 중단·재시작
- `I I` — 실행 중단
- `0 0` — 커널 재시작

### 출력 표시
- `O` — 출력 표시 / 숨기기

### 도움말
- `H` — 단축키 도움말
- `P` — 명령 팔레트

### 코드 자동완성
- `Tab` — 자동완성
- `Tab Tab` — 함수·메서드 매개변수 정보 (일부 Jupyter 환경)

> **참고:** 위에는 Jupyter Notebook에서 널리 사용되는 단축키를 정리했습니다. 일부 키는 Jupyter 버전이나 VS Code Notebook에서 다르게 동작할 수 있습니다. 이번 강의에서 사용하는 VS Code 단축키는 [별도 안내](docs/python-setup/08-shortcuts.md)를 참고하세요. 셀 조작용 알파벳 단축키는 **명령 모드(`Esc`)**에서 사용합니다.
