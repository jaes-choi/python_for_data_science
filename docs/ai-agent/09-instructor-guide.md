## 조교 사전 점검
- Windows 11, macOS(Intel/Apple Silicon), Ubuntu 각각 설치 명령 실행/로그인 확인
- 계정 이용 자격과 무료 한도, 기관 방화벽
- 비교 과제는 **같은 프롬프트·데이터·정답**
- 유료 제품은 강사 계정 시연 또는 동의·승인을 받은 학생만
- 로컬 모델 실습은 RAM/디스크/아키텍처가 허용하는 컴퓨터만
- 인터넷/로그인 장애 시 **참고 구현**과 Python 테스트 실습으로 대체
