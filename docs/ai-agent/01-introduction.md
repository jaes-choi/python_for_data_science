# 01. AI Agent란 무엇인가?

## 학습 목표
AI 채팅과 코딩 에이전트를 구별하고, 작업을 AI에 위임할 때 사람의 책임을 설명합니다.

### 챗봇과 AI Agent
- **AI 채팅:** 사용자가 질문 → AI가 설명 또는 코드를 답함 → 사용자가 직접 복사·실행.
- **코딩 에이전트:** 사용자가 목표·제약·완료 기준을 전달 → AI가 파일 탐색·수정·테스트 등의 도구를 요청 → 실제 결과를 읽음 → 필요하면 계획과 코드를 수정.
- **LLM:** 글과 코드를 생성하는 모델. 에이전트는 그 모델뿐 아니라 **도구·상태·권한·반복 실행 구조**까지 포함한 애플리케이션입니다.

### 에이전트 실행 고리
~~~text
학생(목표·제약·성공 조건)
        ↓
에이전트(계획·다음 행동 선택)
        ↓ 승인 확인
도구(파일 읽기·쓰기·터미널 실행)
        ↓
관찰(출력·오류·테스트)
        └── 미완료 → 재계획·수정 반복
        ↓
완료 보고 → 학생이 검증
~~~

> 에이전트는 만능 자동화 장치가 아닙니다. 틀린 가정을 한 채 여러 파일을 수정할 수 있으므로 **승인 범위와 테스트**가 필요합니다.

## 어떤 지시가 좋은가?
**나쁜 지시:** "쇼핑 프로그램 만들어 줘."

**좋은 지시:**
~~~text
목표: 쇼핑 목록의 품목별 금액과 총액 계산.
입력: 가격 dict, [["우유", 2], ["빵", 3], ["라면", 5]].
제약: 가격이 없으면 임의로 만들지 말고 누락으로 표시.
산출물: agent_lab/shopping.py와 자동 테스트.
성공 조건: 알려진 품목 6,000원, 빵 가격 미정이라 전체 총액은 미확정.
검증: 프로그램과 테스트를 실제 실행한 출력 제공.
안전: data/는 수정하지 말고, 삭제·push·외부 전송 전 승인.
~~~

## 학생에게 질문
1. AI가 코드를 생성만 한 경우와 직접 실행한 경우의 증거는 무엇이 다른가?
2. 에이전트가 "테스트 통과"라고만 보고하면 믿어도 되는가?
3. "빵 가격이 없으면 0원으로 계산"하는 코드가 왜 위험한가?
4. 편리함과 통제 중 무엇을 학생이 직접 결정해야 하는가?

**완료 기준:** 입력·출력·성공 조건·금지할 행동을 포함한 5줄 지시문을 직접 작성합니다.
